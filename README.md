# ARNIX TV

**ARNIX TV** — IPTV-плеер для Android-смартфонов, Android TV и ТВ-приставок. Проект основан на открытом исходном коде [HTWMedia/HTV](https://github.com/HTWMedia/HTV) (Apache-2.0).

## Возможности
- Просмотр IPTV-плейлистов M3U и TVBox.
- Управление пультом ДУ и сенсорным экраном.
- Список каналов по категориям, избранное и телепрограмма EPG.
- Автоматическое переключение на резервный поток, если источник поддерживает несколько ссылок.
- Кэширование списка каналов и настроек.

## Плейлист по умолчанию
При первом запуске используется плейлист:

`http://cdntv.online/high/9n3hebsjat/playlist.m3u8`

Его можно заменить в настройках приложения в разделе «Пользовательский плейлист».

## Сборка
Требуются Flutter 3.13+ и Android SDK:

```bash
flutter pub get
flutter build apk --release --split-per-abi
```

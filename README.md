# ARNIX IPTV

**ARNIX IPTV** — русскоязычный IPTV-плеер для Android-смартфонов, Android TV и ТВ-приставок. Проект основан на открытом исходном коде [HTWMedia/HTV](https://github.com/HTWMedia/HTV) с сохранением условий лицензии Apache-2.0.

## Возможности
- Просмотр пользовательских IPTV-плейлистов M3U и TVBox.
- Русский интерфейс приложения.
- Управление пультом ДУ и сенсорным экраном.
- Список каналов по группам, избранное и телепрограмма EPG.
- Автоматическое переключение на резервный поток, если канал содержит несколько источников.
- Поддержка архива передач, если его предоставляет плейлист.
- Кэширование списка каналов и настроек.

## Сборка APK
Требуются Flutter 3.13+ и Android SDK:

```bash
flutter pub get
flutter test
flutter build apk --release
```

APK создаётся в каталоге `build/app/outputs/flutter-apk/`.
